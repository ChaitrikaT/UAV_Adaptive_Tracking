Condition-Aware Adaptive Perception: video demonstrations

Three different kinds of evidence. Read the label on each one before presenting it.

1. Recorded detector review, Clip 7 REAL FOOTAGE, MEASURED EARLIER

Green = Purdue reference annotation (human labels, with a reference-guided zoom inset for review only). Magenta = independent per-frame detector box (trained YOLO11n, confidence 0.10, 960 px). 120 consecutive frames: 59 with a detector box, 43 with IoU ≥ 0.5, longest unmatched run frames 39–106 (68 frames).

Not shown: tracking IDs, mode switching, speed. Each frame is processed independently.

2. Same video with the saved per-frame numbers ARCHIVED RESULTS REPLAY

The recorded video on top; below it the saved CSV values drawn per frame: max IoU (matched / unmatched), frames where the detector produced a box, and whole-frame brightness and sharpness. The script checks that the CSVs reproduce 120 / 59 / 43 / 68 before drawing anything.

Not shown: anything computed live. No model ran to make this video. The condition plots show that these global values look alike on matched and unmatched frames, so they do not demonstrate that condition estimation explains detector failures.

3. Mechanism illustration SYNTHETIC: NOT UAV DATA

Simulated squares and a hand-written simulated detector. Shows the actual tracker and the actual online FAST/ROBUST switching code on data with known truth: predicted IDs persist, the mode is chosen before each frame's detection, a one-frame false alarm never receives an ID. Summary numbers are in demo/data/synthetic_mechanism_summary.json.

Not evidence of: performance of the trained detector, tracking of real UAVs, or any benefit on Purdue clips.
